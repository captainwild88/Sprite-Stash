# Sprite Stash

Sprite Stash is a personal Fortnite sprite tracker you open in a browser. Click a sprite to mark it owned. That list stays in this browser, on this device. Export and Import in the footer save or restore the list. There is no account.

It is fan-made. It is not affiliated with fortnite.gg or Epic Games. Names and pictures come from [fortnite.gg/sprites](https://fortnite.gg/sprites).

The page is published at <https://captainwild88.github.io/Sprite-Stash/>. Once a day it checks fortnite.gg for new sprites and adds them on its own.
